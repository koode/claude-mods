# claude-mods

Mods for [Claude Code](https://code.claude.com), as a plugin marketplace.

| Mod | What it does |
| --- | --- |
| [idle-compact-bg](plugins/idle-compact-bg) | Idle compaction for background sessions, before the prompt cache expires |

## Install a mod

At the prompt of a terminal session:

```
/plugin install <mod> --marketplace koode/claude-mods
```

From a shell:

```
claude plugin install <mod> --marketplace koode/claude-mods
```
